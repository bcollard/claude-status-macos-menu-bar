Claude Status / Enterprise Extra Usage

Monitor Claude Code Enterprise Extra Usage and monthly spend

On Claude Enterprise, Claude Code usage is governed by a monthly Extra Usage budget set by your admin. This page explains the fields and how to keep the figure visible.

What the Enterprise usage response contains

The OAuth usage endpoint returns null for the standard buckets on Enterprise (five_hour, seven_day and the per-model weekly pools). The relevant block is extra_usage:

"extra_usage": {
  "is_enabled":    true,
  "monthly_limit": 25000,
  "used_credits":  16000.0,
  "utilization":   64.0,
  "currency":      "USD"
}
  • monthly_limit and used_credits are in minor units (cents). 25000 is $250.00, not $25,000.
  • utilization is already a percentage from 0 to 100.
  • The Keychain credential reports subscriptionType: "enterprise" and a rate-limit tier such as default_claude_zero. Pools are managed by an admin and there is no per-user weekly cap.

What Claude Status shows

  • Menu bar title: 64% • $163 (utilization and rounded dollars spent).
  • Dropdown: an Extra Usage row with a progress bar, spend and limit in dollars.
  • Account header: email and organization name from ~/.claude.json.
  • Per-model token breakdown for today and this week from local logs.

Notes for administrators and security teams

  • The only network call is api.anthropic.com/api/oauth/usage, the endpoint Claude Code uses.
  • The app is open source, signed with a Developer ID and notarized. Diagnostics → App Integrity verifies this on the running copy.
  • No analytics or telemetry. The API call can be disabled with Manual only refresh.

Questions

Why does Claude Code on Enterprise show no five-hour or weekly limit?

Enterprise pools are admin-managed. The usage endpoint returns null for those buckets and reports monthly Extra Usage credits instead.

Are Extra Usage amounts in dollars or cents?

The API returns minor units (cents). A monthly_limit of 25000 means $250.00.

How do I see Enterprise Claude Code spend without opening claude.ai?

Install Claude Status. The menu bar shows the Extra Usage percentage and dollars spent, and it refreshes on the cadence you choose.

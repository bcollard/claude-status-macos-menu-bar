Claude Status / Usage limits

Check your Claude Code usage limits from the macOS menu bar

Claude Code does not show a persistent meter for your plan limits. This page explains which limits exist on each plan, where to read them, and how to keep them visible in the macOS menu bar.

Which limits apply to your plan

PlanWhat the usage endpoint reports
Pro, MaxFive-hour utilization and seven-day utilization, each with a reset time. Some accounts also get per-model weekly buckets.
TeamSame buckets as Pro and Max where the plan exposes them.
EnterpriseUsually no five-hour or weekly buckets. Monthly Extra Usage credits with a spend limit and a utilization percentage.

Credit-based models can populate Extra Usage on a Pro account in addition to the five-hour and weekly buckets. Claude Status shows all of them.

Where to read the numbers

  • claude.ai/settings/usage — the web page. Accurate, but you have to open a browser.
  • Inside Claude Code — the /usage command prints the current limits on request.
  • Menu bar — Claude Status polls the same endpoint Claude Code uses and keeps the figures next to the clock.

What the menu bar shows

AccountMenu bar title
Pro or Max5h 13% • wk 2%
Pro with Extra Usage5h 84% • wk 19% • $32
Enterprise64% • $163
No API dataToday's token count, for example 2.7M

The dropdown adds a progress bar per bucket. Colors change at 60% (orange) and 85% (red) so you can read the state without reading the numbers.

Where the data comes from

Claude Status calls GET api.anthropic.com/api/oauth/usage with the OAuth token Claude Code already stored in your macOS Keychain. It is the same call Claude Code makes. The default cadence is every five minutes. On a 429 it honors Retry-After and keeps the last good values on screen.

You can set the cadence in Options → Refresh or switch to Manual only to disable the API call. Local token charts keep working either way.

Install

$ brew tap bcollard/claude-status
$ brew trust --tap bcollard/claude-status
$ brew install --cask claude-status

Requires macOS 14 or later. See the install notes.

Questions

How do I check my Claude Code usage limit?

Run /usage inside Claude Code, open claude.ai/settings/usage, or install Claude Status to keep the five-hour and weekly percentages in the macOS menu bar.

What is the Claude Code five-hour limit?

A rolling usage window on Pro and Max plans. The usage endpoint reports its utilization as a percentage and the time it resets.

Does Claude Status show the same numbers as claude.ai?

Yes. It reads the same usage endpoint that Claude Code uses, so the percentages match claude.ai/settings/usage.
